# 📄 PDF 표 데이터 파싱 실습

표가 많은 PDF 문서에서 데이터를 추출하고, 분석에 쓸 수 있는 형태로 정제해 본 개인 실습입니다.

<sub>대상 문서: 서울대학교 2027학년도 수시모집 모집요강 (75페이지, 서울대학교 입학본부 공개 자료) · 원본 PDF는 저장소에 포함하지 않았습니다.</sub>

<br>

## 🛠 사용 기술

`Python` `pdfplumber` `pandas` `re (정규식)`

<br>

## 📁 파일 구성

| 파일 | 설명 |
|:--|:--|
| `parse.py` | PDF 전체 페이지의 텍스트·표 추출 → `tables.csv` |
| `clean.py` | 모집인원 표 정제 → `모집인원_정제.csv` |
| `모집인원_정제.csv` | 정제 결과 샘플 |

<br>

## ▶️ 실행 방법

<sub>모집요강 PDF를 이 폴더에 `report.pdf`로 저장한 뒤 실행합니다.</sub>

```bash
py -m pip install pdfplumber pandas
py parse.py     # PDF → tables.csv
py clean.py     # tables.csv → 모집인원_정제.csv
```

<br>

## 🔄 진행 과정

| 단계 | 내용 |
|:--|:--|
| **1. 추출** | 75페이지에서 표 535행 추출, 행마다 페이지 번호 기록 |
| **2. 문제 확인** | 추출 결과를 원본 PDF와 대조해 깨진 유형 정리 |
| **3. 정제** | 모집인원 표의 뭉친 셀을 펼치고 숫자 정리 |
| **4. 검증** | 자동 처리가 불가능한 행은 따로 분리 |

<br>

## ⚠️ 추출하면서 발견한 문제

**1. 여러 행이 한 셀로 뭉침**
<br><sub>학과 15개가 한 셀에, 숫자도 `17 7 6 · 6 6 6 5`처럼 한 셀에 들어감 → 표에 행 구분선이 없어 한 행으로 인식됨</sub>

**2. 병합 셀이 빈칸으로 나옴**
<br><sub>일정 표의 "구분" 열이 비어 날짜만 남음 → 병합 셀 값이 첫 행에만 들어감</sub>

**3. 열이 밀림**
<br><sub>같은 표인데 페이지 중간부터 학과명이 한 칸 왼쪽 열에 들어감 → 표 안에서 구조가 바뀜</sub>

**4. 각주가 숫자에 붙음**
<br><sub>`17(42))`, `206(42))` → 각주 표시가 같은 셀로 추출됨</sub>

**5. 숫자가 문자열로 나옴**
<br><sub>`"1,529"`, 값 없음은 `·` → 원본 표기 그대로 추출됨</sub>

**6. 페이지마다 헤더 반복**
<br><sub>같은 헤더가 9·10·11페이지마다 다시 나옴 → 표가 여러 페이지에 걸침</sub>

**7. 표가 아닌 내용도 표로 잡힘**
<br><sub>신청서 서식, 긴 안내문이 셀 하나짜리 표로 들어옴 → 테두리가 있는 영역을 모두 표로 인식함</sub>

<br>

## 🧹 정제 내용 (`clean.py`)

| 작업 | 방법 |
|:--|:--|
| 뭉친 셀 펼치기 | 학과명과 숫자를 공백으로 쪼개 학과 하나 = 행 하나 |
| 숫자 정리 | 정규식으로 각주 제거, 쉼표 제거, `·` → 0, 정수 변환 |
| 불필요한 행 제외 | 반복 헤더와 소계 행 제거 |
| 개수 검증 | 학과명 개수 = 숫자 개수일 때만 펼치고, 다르면 따로 출력 |

<br>

## ✅ 결과

- 학과 **76개**를 학과별 행(지역균형 · 일반 · 기회균형 · 합계)으로 정제
- **2개 행**은 개수가 맞지 않아 자동 처리에서 제외

| 페이지 | 학과명 | 숫자 | 원인 |
|:--:|:--:|:--:|:--|
| 9 | 8개 | 7개 | 숫자가 없는 상위 학부명 `물리·천문학부`가 섞임 |
| 11 | 5개 | 4개 | 숫자가 없는 상위 학부명 `소비자아동학부`가 섞임 |

<sub>위치만으로 짝을 맞추면 값이 어긋나게 들어가기 때문에 확인 대상으로 남겼습니다.</sub>

## 💡 배운 점

- **추출보다 정제와 검증에 시간이 더 듭니다.** 추출은 몇 줄이면 되지만, 표마다 깨지는 방식이 달라 정제 규칙을 따로 잡아야 했습니다.
- **검증 조건을 먼저 두는 것이 중요합니다.** 개수 검증이 없었다면 2개 행이 학과와 숫자가 어긋난 채로 저장됐을 것입니다.
- **페이지 번호를 남겨 두면** 원본과 대조하기 쉽습니다.
